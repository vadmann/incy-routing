RoscomVPN FIX: отдельный профиль маршрутизации для INCY Android

Серверов, паролей и VPN-подписок в пакете нет. Профиль используется
с выбранной в Incy подпиской.

Обновление
GitHub Actions запускает build.py каждые 6 часов и по ручному запуску.
Скрипт получает актуальные AS45090, страны РФ/Беларусь, дополнительный
белый список hxehex и проверяет категории RoscomVPN GeoIP/GeoSite.
Публикация profile.json происходит только после успешной сборки.
При сбое сборки ранее опубликованный профиль сохраняется.
Новая LastUpdated инициирует проверку геофайлов при обновлении профиля.

После размещения в публичном GitHub-репозитории:
incy://autorouting/onadd/https://raw.githubusercontent.com/OWNER/REPO/main/profile.json

Incy обновляет Autorouting по умолчанию раз в 24 часа. Планировщики
GitHub и Android могут задерживать обновление. Пользовательские настройки
интервала в приложении имеют значение. Фактический импорт и обновление
на Android необходимо проверить после публикации.

Ограничения совместимости
Все исходные элементы правил включены в профиль напрямую либо через
одноимённые геокатегории. Произвольная последовательность Shadowrocket
не представима обычными группами Incy: используется block-proxy-direct.
Ранние DIRECT (AS45090, Aqara и другие) могут уступить Block/Proxy.
GEOIP использует другую базу классификации стран; результат может
отличаться от встроенного GEOIP Shadowrocket.
force-remote-dns, no-resolve, extended-matching и системные параметры
General, включая ipv6=false, не являются настройками этого профиля.
Поэтому пакет не подтверждает полную функциональную эквивалентность
Shadowrocket. Не заменяйте им рабочий профиль без проверки ограничений.
